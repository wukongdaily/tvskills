### Fire TV的遥测和广告

| 包 | 作用 |
|---|---|

| `com.amazon.device.telemetry.emitter` | 遥测发射器（Fire OS 8） |
| `com.amazon.wirelessmetrics.service` | 无线网络指标 |
| `com.amazon.perfcollection` / `com.amazon.perfc` | 性能数据采集 ×2 |
| `com.amazon.dp.logger` | 数据管道日志 |
| `com.amazon.ceviche` | 数据采集管道（CEV） |
| `com.amazon.tv.developer.dataservice` | 第三方应用内容个性化数据 |
| `com.amazon.livedeviceservice` | 设备注册服务 |
| `com.amazon.privacypassservice` | privacy pass 令牌 |
| `com.amazon.wifilocker` | **向亚马逊上传 Wi-Fi 密码** |
| `com.amazon.tv.acr` | 自动内容识别（正在看什么） |
| `com.amazon.ftvspatial` | 在场/室内定位感知 |
| `com.amazon.neo.minerva` / `.logcat` | ML/遥测管道 ×2 |
